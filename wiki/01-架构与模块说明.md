# 01. 架构与模块说明

## 顶层结构

- `app/layout.tsx`
  - 注入全局字体变量
  - 用 `SmoothScroll` 包裹页面内容
- `app/page.tsx`
  - 页面结构主入口（Hero / Proof / Call）
  - 挂载 `GlowRiver` 与 `HomeScrollChoreography`

## 关键模块

### 1) 滚动与动画编排

- `components/smooth-scroll.tsx`
  - 初始化 Lenis
  - 与 ScrollTrigger 同步
- `components/home-scroll-choreography.tsx`
  - 页面文案入场与滚动联动（只做位移/裁切）
  - 桌面端 pin 策略（manifesto/proof）

### 2) 背景系统

- `components/glow-river.tsx`
  - SVG 渐变路径（主路径 + shimmer 路径）
  - 低频漂移/呼吸，营造“暗流”
- `components/home-call.tsx`
  - 右侧光球（orb + core 双层）
  - 呼吸与轻浮动动画

## 依赖关系（简化）

`layout -> SmoothScroll`  
`page -> GlowRiver + Hero/Proof/Call + HomeScrollChoreography`

## 维护规则

- 所有 GSAP 动画必须放在 `gsap.context()` 内，确保可回收
- Pin 逻辑使用 `matchMedia` 按断点隔离
- 背景特效必须优先保证流畅性与可读性
