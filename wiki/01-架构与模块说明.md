# 01. 架构与模块说明

## 顶层结构

- `app/layout.tsx`
  - 注入全局字体变量
  - 挂载 `ShaderFieldRoot`（背景层）
  - 用 `SmoothScroll` 包裹页面内容
- `app/page.tsx`
  - 页面结构主入口（Hero / Proof / Call）
  - 挂载 `GlowRiver` 与 `HomeScrollChoreography`

## 关键模块

### 1) 滚动与动画编排

- `components/smooth-scroll.tsx`
  - 初始化 Lenis
  - 与 ScrollTrigger 同步
  - 广播 `LENIS_SCROLL_EVENT`（scroll/velocity）
- `components/home-scroll-choreography.tsx`
  - 页面文案入场与滚动联动（只做位移/裁切）
  - 桌面端 pin 策略（manifesto/proof）

### 2) 背景系统

- `components/glow-river.tsx`
  - SVG 渐变路径（主路径 + shimmer 路径）
  - 低频漂移/呼吸，营造“暗流”
- `components/home-call.tsx`
  - 右侧光球（orb + core 双层）
  - 呼吸与轻浮动动画

### 3) WebGL（可降级层）

- `components/shader-field/shader-field-root.tsx`
  - 自动档位判定（high/balanced/safe）
  - 冷启动校准、运行时低帧关停
- `components/shader-field/shader-field-canvas.tsx`
  - Canvas 参数（dpr/powerPreference）
  - 低帧监控、context lost 监听
- `components/shader-field/life-field-scene.tsx`
  - FBO ping-pong（状态演化）
  - 按档位调 `grid` 与 `steps`
- `components/shader-field/life-field-shaders.ts`
  - GOL 模拟与显示着色器

### 4) 跨模块事件

- `lib/lenis-scroll-event.ts`
  - 统一定义自定义事件与类型
  - 作为 Lenis 与 WebGL 的低耦合桥接

## 依赖关系（简化）

`layout -> SmoothScroll + ShaderFieldRoot`  
`SmoothScroll -> LENIS_SCROLL_EVENT -> ShaderFieldCanvas/LifeFieldScene`  
`page -> GlowRiver + Hero/Proof/Call + HomeScrollChoreography`

## 维护规则

- 所有 GSAP 动画必须放在 `gsap.context()` 内，确保可回收
- Pin 逻辑使用 `matchMedia` 按断点隔离
- WebGL 不得阻塞首屏可读性，关闭时页面必须视觉完整
