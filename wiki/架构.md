| 命令 | 说明 |
|------|------|
| `npm run dev` | 开发 |

## 首页纵向顺序（`app/page.tsx`）

`#manifesto` Hero → Proof 内容一览 → `#founders` 片场四屏 → 海沟 → `#social` → `#call`（含 `#fit` 锚点）→ Footer。

顶栏锚点：`lib/site-nav.ts`（宣言 / 片场 / 触点 / 联络）。

背景栈：`SgAmbientGrid`、`GlowRiver`、`WaterVolumeFx`、`UnderwaterLightStage`（读 `--depth-t` / `--ambient-mode`）。编排挂载：`HomeScrollChoreography`。

## B 站（唯一 iframe 实现）

- `bilibili-embed-player.tsx` + `lib/bilibili-player.ts`（`aid/cid` 直出 URL）
- 预取：`useFounderPanelPrefetch` 用 **滚动测量**（`getBoundingClientRect`），**勿**对 `IntersectionObserver` 使用 `vh` 的 `rootMargin`
- 离屏暂停：`lib/bilibili-embed.ts` → `pauseBilibiliEmbed`

## Lenis 与 ScrollTrigger

- 全站 ST 由 `HomeScrollChoreography` + `components/motion/*` 创建。
- `SmoothScroll` 卸载 Lenis 时会 **`ScrollTrigger.getAll().forEach(kill)`**；勿在别处再挂一套 ST。
- `--depth-t` 仅由 `register-global-depth-scrub.ts` 的 `formatSafeDepthProgress` 写入（有限数、`[0,1]`）。

## 关键 Client 边界

`SmoothScroll`、`HomeScrollChoreography`、`HeroWaveCanvas`（layout 全局）、`GlowRiver`、各 `home-*` 区块内 Client 子树。

## 环境变量

| 变量 | 作用 |
|------|------|
| `NEXT_PUBLIC_SITE_URL` | 站点绝对 URL |
| `NEXT_PUBLIC_SG_WEBGL` | `off` 关 WebGL |
| `NEXT_PUBLIC_GSAP_DEBUG` | `1` 显示 ST markers |
| `NEXT_PUBLIC_BUILD_TIME` | 构建日（避免 hydration 抖动） |
