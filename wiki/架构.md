## `layout.tsx` 壳层（自上而下）

`SmoothScroll` → `SgPerformanceGuards` → `HeroWaveCanvas`（全局）→ `data-scroll-depth-root`（页面内容）。

## 首页纵向顺序（`app/page.tsx`）

`#manifesto` → `#mission` → `#proof`（人物特稿）→ `#dialogue`（视频播客）→ `#founders`（三条内容线）→ `#events`（活动）→ `#social`（渠道）→ `#call`（联系）→ `#fit`（空壳锚点）→ Footer。

顶栏锚点：`lib/site-nav.ts`（最新 / 栏目 / 活动 / 渠道）。

## 联络 `#call`（`home-call.tsx`）

`#call-join` 集中呈现故事提交标准、微信 `x3167056428`、小浪二维码与 Discord；区块底部提供内容采访和活动合作邮箱（`lib/site-contact.ts`）。

`#fit`：`HomeFit` 为 **sr-only 空壳**，匹配度文案已并入 `call-join`；桌面 ST `fit-closing-pin` 仍挂 `#fit`。

## 触点 `#social`

- 数据：`lib/social-channels.ts`，只维护实际上线的微信、B 站、小红书与 GitHub。
- UI：`home-social.tsx` 以四个外链入口呈现长文、长视频、现场短片与开放资料。
- 微信入口指向最新人物特稿；页脚「人物特稿」回到 `#proof`。

## B 站（唯一 iframe）

| 文件 | 作用 |
|------|------|
| `bilibili-embed-player.tsx` | iframe；`aid/cid` 同步出 `src` |
| `lib/bilibili-player.ts` | URL、meta、`prefetchBilibiliPlayerDocument` |
| `lib/use-founder-panel-visible.ts` | 可见 ≥8%；预取 = 滚动测量（**禁止 IO `vh` rootMargin**） |
| `lib/bilibili-embed.ts` | `pauseBilibiliEmbed` |

`layout` 已对 `player.bilibili.com` / `api.bilibili.com` 做 `preconnect`。

## WebGL 分级（`lib/sg-webgl-policy.ts`）

| `NEXT_PUBLIC_SG_WEBGL` | 效果 |
|------------------------|------|
| 未设 / `off` | **默认**：无 Canvas，仅 CSS 氛围 |
| `lite` | 仅 Hero 海面，无 Bloom |
| `full` | Hero + Bloom + `WaterVolumeFx` |

`prefers-reduced-motion` 强制 `off`。

## 运行时节能（`sg-performance-guards.tsx`）

- 标签页隐藏：`gsap.ticker.sleep()` + `data-doc-hidden`。
- Hero 几乎离屏：`data-sg-atmosphere-paused` → `UnderwaterLightStage` / `WaterVolumeFx` 停更。

## Lenis 与 ScrollTrigger

- ST 仅由 `HomeScrollChoreography` + `motion/register-*` 创建；卸载时 **`gsap.context` + `matchMedia` revert**（见 `home-scroll-choreography.tsx`）。
- 启动顺序、钉顶、视口锁见 **[规则.md](./规则.md)** §2、§5。
- `--depth-t` 仅 `register-global-depth-scrub.ts` → `formatSafeDepthProgress` 写入。
