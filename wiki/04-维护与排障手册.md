# 04. 维护与排障手册

## 常见故障与处理

### 1) 刷新后背景亮度先黑后浅

现象：首屏短时间内亮度突变。  
优先检查：

- 是否有延迟挂载的背景层导致“后出现”
- 是否有正文/容器 opacity 动画影响观感
- WebGL clearColor 与 CSS 背景是否一致

处理原则：

- 首帧视觉必须可预测
- 能稳定就先静态，后续再逐步恢复动态

### 2) 文字偶发“抽白/闪变”

现象：正文偶发从暗白变亮白。  
优先检查：

- GSAP 是否对正文使用了 `opacity/autoAlpha` scrub
- 是否多动画叠加在同一文本节点

处理原则：

- 正文只做位移/裁切，不改透明度
- 对比度由固定颜色变量提供，不依赖动画

### 3) WebGL 卡顿严重

优先检查：

- 当前分档是否正确（`high/balanced/safe`）
- dpr 是否过高
- grid/steps 是否过重
- watchdog 是否误判低帧

处理顺序：

1. 先验证自动降级是否触发
2. 再降 dpr 与 steps
3. 必要时临时 `NEXT_PUBLIC_DISABLE_WEBGL_BG=1`

补充检查：

- 确认 watchdog 使用真实帧统计（`requestAnimationFrame`）而非 `setTimeout` 直接算 FPS
- 确认冷启动校准窗口在切档后会重置

### 4) Safari iOS 闪烁/撕裂

优先检查：

- `clip-path + pin` 组合是否同时作用于同层
- 是否缺少 `matchMedia` 条件隔离
- 是否存在过重滤镜叠加

### 5) `npm run lint` 与 WebGL 可变对象

当前状态：全量 `npm run lint` 已通过。  
说明：`life-field-scene.tsx` 对 Three uniforms 可变写入点使用了最小范围规则豁免。

维护建议：

- 仅在必须的 WebGL 可变写入点使用豁免注释
- 若重构 scene 逻辑，优先保持渲染语义正确，再评估 lint 规则适配
- 避免为“消灭豁免”而改写渲染路径，导致性能或视觉回归

## 发布前检查清单

- A11y：
  - `prefers-reduced-motion` 下动效全部优雅降级
- Performance：
  - 中端移动端滚动无明显连续卡顿
  - 长时间浏览无持续升温/掉帧恶化
- Cross-browser：
  - Chrome / Safari（iOS）/ Edge 回归通过
- Stability：
  - 刷新后亮度恒定
  - 正文颜色无闪变
  - 自动分档不会在静置阶段异常降到 `safe`

## Agent 协作约定

- 提交改动前，必须记录：
  - 改动目标
  - 涉及模块
  - 对性能与可读性的影响
- 任何“观感修复”都要附带“性能回归检查”
- 禁止在未知影响下大范围调整动画参数
