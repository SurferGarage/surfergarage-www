## 0. 系统定义（System Definition）

Surfer Garage **不是**一个普通网站。

它是一个面向 **Surfing Founders** 的 **Media Signal Operating System（媒体信号操作系统）**。

界面应同时像：

| 隐喻 | 职责 |
|------|------|
| **Bloomberg Terminal** | 信息密度、可扫读的数据层 |
| **Editorial Magazine** | 叙事层、封面故事、引文 |
| **Signal Radar Control Room** | 实时媒体流、强度、状态 |
| **Developer Network Graph** | 人物节点、关系、连接 |

**最终形态判断（不可偏离）：**

> 一个「创作者信号观测与记录系统」

**不是：** blog · 传统 media site · portfolio · SaaS dashboard

## 1. 核心设计原则（Core Design Principles）

### 1.1 Signal over Content

所有内容不是「文章」，而是：

- **Signal**（信号）
- **Strength**（强度）
- **Node**（节点）
- **Flow**（流动）

任何 UI 都必须能表达 **信号状态**（新 / 强 / 弱 / 归档 / 待公布）。

### 1.2 Editorial over UI

UI 不是组件堆叠，而是 **编辑过的视觉叙事**。  
每个区块应能回答：这一屏在讲什么故事、读者下一步该看什么信号。

### 1.3 Minimal Surface, Dense Meaning

- 表面极简
- 信息密度高
- **Hover / Focus 才展开深层信息**（默认不堆满）

### 1.4 Motion = Signal Flow

动画不是装饰，而是：

- wave propagation（波传播）
- signal pulse（信号脉冲）
- node activation（节点激活）

动效边界见 [动效.md](./动效.md)：**禁止正文滚动改 opacity**；尊重 `prefers-reduced-motion`。

## 2. Design Tokens（设计系统变量）

### 2.1 Color System

协议 token → 网站 CSS 变量映射：

| 协议 | 色值 | 网站 `globals.css` |
|------|------|---------------------|
| `--bg-primary` | `#0b0c10` | `--paper-0` |
| `--bg-secondary` | `#1e2128` | `--paper-3` |
| `--brand-blue` | `#0009e2` | `--brand-primary` |
| `--accent-cyan` | `#27d7c7` | `--brand-teal` |
| `--text-primary` | `#e6e9ef` | `--foreground` |
| `--text-secondary` | `#8b90a0` | `--muted` / `--brand-cool-grey` |
| `--stroke` | `rgba(255,255,255,0.08)` | `--hairline` |

改色顺序：**先 `globals.css` → 再 `lib/sg-brand.ts`（OG/metadata）**。

### 2.2 Typography System

| Layer | Font | Usage | 网站类名 / 变量 |
|-------|------|-------|-----------------|
| H1 / Editorial Title | Instrument Serif | Cover story / hero | `editorial-serif` · `--font-serif` |
| Body / UI | Noto Sans SC | Interface / content | `--font-zh` |
| Data / Signal | IBM Plex Mono | metrics / tags / system | `editorial-mono-tabular` · `--font-mono` |
| 中文引文（可选） | Noto Serif SC | 长引文 | `editorial-serif-zh` |

### 2.3 Spacing System

基准阶梯：`4, 8, 12, 16, 24, 32, 48, 64, 96, 128`（px）

| 场景 | 建议 |
|------|------|
| Section gap | 96–128 |
| Card gap | 24–32 |
| Micro interaction | 8–12 |

### 2.4 Grid System

**Desktop（1440）**

- 12 column
- margin: 80px
- gutter: 24px

**Mobile（390）**

- 4 column
- margin: 16px
- gutter: 12px

现站部分区块用 `SG_PAGE_SHELL_CLASS`（见 `lib/sg-layout.ts`）；重设计时 **统一到新栅格 token**，避免片场全宽与居中栅格混用无文档。

## 3. UI Component System（组件系统）

以下为 **v1.0 目标组件**；括号内为现站近似实现，供迁移对照。

### 3.1 SignalCard（核心内容卡）

**Structure**

```
[Tag Capsule]
Title (Serif optional)
Description (Sans)
Meta: time / duration / strength
Signal line indicator
```

**Behavior**

- hover → cyan border draw
- hover → signal strength animation
- click → expand into detail view（或外链公众号 / B 站）

**现站对照**：微信 Vol 行、视频 Vol chip、触点渠道卡 → 收敛为同一 `SignalCard` API。

### 3.2 CapsuleTag（分类标签）

**Types：** `INSIGHT` · `MEDIA` · `YOUTH` · `LIVE`

**Style：** `border-radius: 999px` · thin stroke · cyan active glow

**现站对照**：`SgVisPill` · `lib/sg-vis.ts` · `visPillForFounderKind()`

| 片场模块 | 胶囊 |
|----------|------|
| 人物访谈 | INSIGHT |
| 视频播客 | MEDIA |
| Startup Playbook | YOUTH |
| 视觉车库 | LIVE |

### 3.3 NodeLine（信号线系统）

用于：卡片连线 · 区块分隔 · 背景结构

**Behavior：** slow wave animation · directional flow **left → right**

**现站对照**：`SgVisSignalStrip` · `SgVisWaveRule` · `.sg-wechat-vol-option::before`

### 3.4 VideoFrame（片场视频模块）

- aspect ratio: **16:9**
- dark overlay ~20%
- hover autoplay preview（muted，可选）
- bottom-left: title overlay
- bottom-right: signal strength

**现站对照**：`.sg-video-media-frame` · `BilibiliEmbedPlayer` · 左栏封面框

### 3.5 FounderNode（人物节点）

**Structure：** avatar（minimal）· name · domain tag · connection count  

**Hover：** expands connections graph（可选，P2）

**现站对照**：嘉宾名单 `GuestRoster` · 联络区 `team-member-portrait`

### 3.6 EditorialQuote（编辑引文）

- Font: EB Garamond / Instrument Serif italic fallback
- Style: left border cyan line · large line-height · max-width ~60%

**现站对照**：待建；Hero / 文章页可复用。

## 4. Page Architecture（页面结构 · 目标 IA）

以下为 **重设计目标信息架构**。与现站映射见 §5。

### 4.1 HERO — Signal Origin Layer

**Desktop layout（概念）**

```
[LOGO]                    [LIVE / ARCHIVE]

              SURFER GARAGE
        Ride the wave. Build what matters.

        [ LIVE SIGNAL STREAM ]
        - Founder Interview: …
        - Episode #14: …
        - Event: …
```

**Background：** animated waveform grid · slow pulse nodes  

**Interaction：** scroll → signal strengthens · hover → waveform reacts  

**现站锚点**：`#manifesto` · `home-hero.tsx`

### 4.2 CONTENT INDEX — Signal Feed

**Layout**

- Left **8 cols**：feed
- Right **4 cols**：featured insight

Each card = **signal entity**

**Sorting modes：** Latest · Strongest Signal · Founders · Media Drops

**现站锚点**：`#proof`（`home-proof`）偏静态数字 → **升级为 Signal Feed**

### 4.3 FIELD ZONE —「4 Screens」（片场）

| Screen | 协议命名 | 现站模块 | 形态 |
|--------|----------|----------|------|
| 1 | Interview Stream | 人物访谈 | video / cover dominant · transcript overlay（可选） |
| 2 | Builder Diary | 视频播客 | 三栏工作台 · B 站播放器 |
| 3 | Event Map | （新）或 视觉车库演进 | node graph · location signals |
| 4 | Playbook | Startup Playbook | structured editorial · serif headers |

**现站锚点**：`#founders` · `lib/founder-panels.ts` · 四屏 sticky stack

> **注意**：协议 Screen 1/2 与现站「微信 / 视频」顺序不同。重设计时以 **产品优先级 + 用户路径** 定稿，再改 `FOUNDER_STACK_MODULES` 顺序。

### 4.4 SIGNAL CTA ZONE

不用「Join us」，用：

**Become a Signal Node**

Actions：Submit Story · Join Network · Collaborate · Media Kit  

Interaction：hover → node activation ripple  

**现站锚点**：`#call` · `home-call.tsx`（加入车库 / Founders / 微信）

### 4.5 FOOTER — Control Panel

Terminal-like · low-opacity grid  

Content：contact · press · social · API-like media access  

**现站对照**：`site-footer.tsx` · 可演进为「控制面板」视觉

## 5. 与现站对照 & 重构优先级

| 优先级 | 区域 | 问题 | 目标 |
|--------|------|------|------|
| **P0** | `#founders` 片场母版 | 四屏像四个站点；顶栏/内容区双层盒子 | 统一 FullBleed shell + Signal 语言 |
| **P0** | 视频播客三栏 | 对齐 / 媒体框 / 封面 letterbox 反复改 | `VideoFrame` + subgrid 母版 |
| **P0** | 人物访谈 | Vol 列表 + 封面拼贴感 | `SignalCard` 列表 + 统一 INSIGHT 层 |
| **P1** | `#proof` | 仅数字条，无 signal 语义 | 升级为 Signal Feed（8+4 栅格） |
| **P1** | `#social` 触点 | 渠道卡层级散 | 媒体矩阵 + 主信号（微信 / B 站） |
| **P1** | Hero | 缺 LIVE SIGNAL STREAM | 保留海面 WebGL，加信号 ticker |
| **P2** | `#call` | 文案仍是「加入车库」 | 渐进改为 Signal Node CTA |
| **P2** | Footer | 常规页脚 | Control Panel 视觉 |

**推荐落地顺序：**

1. Design Tokens + 组件 Figma/AI 稿（SignalCard · CapsuleTag · NodeLine · VideoFrame）  
2. 片场母版 + 视频播客 + 人物访谈（P0）  
3. Signal Feed 替换 Proof（P1）  
4. Hero 信号流 + 触点矩阵（P1）  
5. CTA / Footer 语义升级（P2）

## 6. Motion System（动效规范）

| 名称 | 参数 | 语义 |
|------|------|------|
| **Signal Pulse** | 2.4s infinite · ease-in-out · opacity 0.2→1→0.2 | 节点存活 / 新信号 |
| **Hover Sweep** | cyan border 顺时针绘制 · 300ms ease-out | 可交互卡 |
| **Scroll = Amplification** | 非「翻页」，是信号增强 | 见下表 |

**Scroll 阶段（与现站 depth 叙事对齐）**

| 阶段 | 位置 | 信号强度 |
|------|------|----------|
| Entry | Hero | weak |
| Mid | Proof / Feed | stable |
| Field | 片场四屏 | peak |
| CTA | 联络 | dispersing |

实现须走 `sg-home-registry`；详见 [动效.md](./动效.md)。

## 7. AI Prompt Compatibility Layer

给 **Cursor / v0 / Figma AI** 用的系统 Prompt（英文，便于模型执行）：

```text
Design a media operating system website called “Surfer Garage”.

It is NOT a SaaS dashboard.
It is a Signal-based Editorial Media OS for “Surfing Founders”.

Visual style:
- Dark background (#0b0c10 → #1e2128)
- Electric Blue (#0009e2)
- Cyan accents (#27d7c7)

Typography:
- Instrument Serif for editorial headlines
- Noto Sans SC for UI text
- IBM Plex Mono for data / signal metrics

Layout:
- 12 column grid desktop (margin 80, gutter 24)
- 4 column mobile (margin 16, gutter 12)
- Minimal surface, dense meaning
- Editorial spacing (section gap 96–128)

Core components:
SignalCard, CapsuleTag, NodeLine, VideoFrame, FounderNode, EditorialQuote

Motion:
signal pulse, wave flow, hover sweep cyan line
Scroll = signal amplification (not page-flip decoration)

Do NOT use:
bento grid, heavy rounded UI, light background, purple gradients,
generic SaaS dashboard, Inter font
```

**中文模块 Prompt（片场 / 视频三栏 / 微信专栏）** 见对话记录或后续 `wiki/前端设计协议-模块Prompt.md`（待补）。

**代码复现 Prompt（Next.js 仓库）**

```text
Implement the attached design in surfergarage-www (Next 16, Tailwind 4).

Rules:
- Data: lib/wechat-official-feed.ts, lib/surfing-founders-video-season.ts — extend, don’t fork
- Styles: app/globals.css tokens + .sg-* classes first
- Motion: no new GSAP without sg-home-registry entry
- WebGL: default off (sg-lazy-*)
- a11y: listbox patterns, prefers-reduced-motion

Deliver minimal diff + npm run build green.
```
