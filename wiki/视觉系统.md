## 其他图形

- **波浪 / 流动**：`GlowRiver`、Hero WebGL、`--wave-scroll-vel`。
- **节点 / 连线**：`sg-wechat-vol-option::before`、chip 边框。

## WebGL 与性能

| `NEXT_PUBLIC_SG_WEBGL` | 效果 |
|------------------------|------|
| 未设 / `off` | 仅 CSS 氛围（**默认**） |
| `lite` | Hero 海面 |
| `full` | Hero + Bloom + `WaterVolumeFx` |

`off` 时通过 `sg-lazy-*` **不加载** three.js 模块图。

## 改视觉时顺序

1. 重设计阶段：先读 [前端设计协议.md](./前端设计协议.md) 确认 IA / 组件目标。  
2. 先改 `app/globals.css` 变量（或同步 `lib/sg-brand.ts` 供 metadata/OG）。  
3. 再改区块组件（`home-hero`、`home-social`…）。  
4. 动效边界见 [动效.md](./动效.md)；分支见 [规则.md](./规则.md)。

## 工程

- WebGL 懒加载：`components/sg-lazy-hero-wave.tsx`、`sg-lazy-water-volume.tsx`  
- 本地开发：`npm run dev` → **http://localhost:3789**  
- 省内存：`npm run dev:preview`
