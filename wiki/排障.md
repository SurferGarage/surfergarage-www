# 排障与发布

## 常见报错

### `IntersectionObserver: rootMargin must be specified in pixels or percent`

片场视频不加载。IO **不支持 `vh`**。用 `lib/use-founder-panel-visible.ts` 的滚动测量，勿写 `rootMargin: "50vh"`。

### ScrollTrigger 全失效

`SmoothScroll` 卸载时 `kill` 了全部 ST。整页刷新；或检查是否刚切换「减少动态效果」。

### 滚到底背景发灰 / 竖条

`:root --depth-t` 变成 `NaN`/`Infinity` 字符串 → `color-mix` 失效。确认仅 `formatSafeDepthProgress` 写入；`WaterVolumeFx` 中 `smoothstep` 须 `edge0 < edge1`；`footer` 有实底 `bg-[var(--background)]`。

### Hero 底黑带、Proof 顶跳色

勿用整页 % 结束水下层。保持 `sg-main-depth-paper` + `submerge` **118vh** + `#manifesto::after`；勿插 bridge 条。

### Hydration mismatch（`<html className>`）

`<html suppressHydrationWarning>`；动态时间用 `hero-rec-clock`；`lib/site-version.ts` 勿顶层 `new Date()`。

### 首屏 WebGL 空白

系统「减少动态效果」会故意不挂载；查 shader 报错与 `[data-hero-wave]`。

### `next build` 字体失败

构建机需访问 `fonts.gstatic.com`，或改自托管字体。

### Turbopack workspace root 警告

在 `surfergarage-www` 目录执行构建；`next.config.ts` 已设 `turbopack.root`。

## 性能排查顺序

1. 关 shimmer、降 Glow blur  
2. Hero 离屏是否停帧  
3. 是否误开第三路 WebGL  
4. Safari：`clip-path` + pin 是否过重  

## 发布前检查

- [ ] `npm run lint` / `npm run build` 通过  
- [ ] `NEXT_PUBLIC_SITE_URL` 已设  
- [ ] `prefers-reduced-motion` 下可读、无 WebGL  
- [ ] 中端机滚动无明显卡顿；离屏 Hero 停帧  
- [ ] 片场 B 站可播、微信链为真实文章 URL  
- [ ] Chrome / Safari / Edge 抽测锚点跳转  
- [ ] `/privacy`、OG 图、sitemap 可访问
