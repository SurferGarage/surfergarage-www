# 动效与性能

> 代码入口：`lib/sg-motion-system.ts`（常量）· `components/motion/sg-home-registry.ts`（注册顺序）· `components/home-scroll-choreography.tsx`（挂载）。

## 硬约束

- 正文区：**禁止**滚动 scrub `opacity` / `autoAlpha`；只做位移 / `clip-path`。
- `prefers-reduced-motion: reduce`：不注册 Lenis 与编排内 ST；`--depth-t` 固定 `0`。
- 氛围以 CSS/SVG 为主；全屏 WebGL 仅 Hero + 首页 `WaterVolumeFx` 两路，勿再加第三路常驻 Canvas。

## 分层 L0–L3

| 层 | 内容 | 主要 `register-*` |
|---|------|-------------------|
| L0 | 全页 `--depth-t`、Hero 浪面收束 | `global-depth-scrub`、`hero-choreography` |
| L1 | Manifesto / Hero 字标与段落 | `manifesto-scroll`、`hero-wordmark-stagger`、`hero-choreography` |
| L2 | 片场 intro、呼吸带、GitHub、社交、Call、Footer 字标 | `founders-intro`、`founder-breath`、`github-repo-cards`、`social-expand`、`call-reveal`、`footer-wordmark-reveal` |
| L3 | 桌面 pin（Manifesto 侧栏 + 四屏片场 + Fit 收尾） | `desktop-pins`、`fit-closing-pin`（仅 `md+`） |

Pin 起点：`start: "top 72px"`（与 sticky header 对齐，用 **px** 勿用 rem）。

## 注册顺序（`reduced` 关闭时）

1. `registerGlobalDepthScrub`  
2. `registerManifestoScroll`  
3. `registerHeroWordmarkStagger`  
4. `registerHeroChoreography`（含 `#founders` 浪面 calm）  
5. `registerFoundersIntro` → `registerFounderBreath` → `registerGithubRepoCards`  
6. `registerSocialExpand` → `registerCallReveal` → `registerFooterWordmarkReveal`  

`< md`：`registerFitReveal`。`md+`：`registerDesktopPins`、`registerFitClosingPin`、`registerMagnetHover`。

## CSS 变量分工

| 变量 | 写入 | 读取 |
|------|------|------|
| `--depth-t` | `register-global-depth-scrub` | `globals.css`、`UnderwaterLightStage`、`WaterVolumeFx`、`hero-wave-canvas` |
| `--wave-scroll-vel` | `wave-scroll-velocity-bridge` | Hero / `WaterVolumeFx` |
| `--wave-distortion` / `--wave-opacity` | Hero calm ST | Hero Shader |

## WebGL 与降级

| 组件 | reduced-motion | 离屏 |
|------|----------------|------|
| `HeroWaveCanvas` | 不挂载 | IO → `frameloop="never"` |
| `WaterVolumeFx` | 不挂载 | 当前常开；卡顿再改 `demand` |
| `GlowRiver` | CSS 降级 | — |

调参顺序：**Glow** 先降 blur/振幅 → **Hero** 先 Bloom/opacity → 再动 shader 复杂度。`dpr` 上限 1.5。
