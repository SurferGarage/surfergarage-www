# 动效与性能

> 入口：`lib/sg-motion-system.ts` · `components/motion/sg-home-registry.ts` · `components/home-scroll-choreography.tsx`  
> **审查**：2026-05-29 · 与 `SG_HOME_MOTION_PIPELINE` 一致。

## 硬约束

- 正文：**禁止**滚动 scrub `opacity` / `autoAlpha`。
- `prefers-reduced-motion`：不注册 Lenis / 编排 ST；`--depth-t: 0`。
- WebGL 默认 **off**；仅 `full` 时挂载 `WaterVolumeFx`（见架构篇 WebGL 表）。

## 分层 L0–L3

| 层 | 内容 | `register-*` |
|---|------|----------------|
| L0 | `--depth-t`、Hero 浪面 calm | `global-depth-scrub`、`hero-choreography` |
| L1 | Manifesto / Hero 字标 | `manifesto-scroll`、`hero-wordmark-stagger`、`hero-choreography` |
| L2 | 片场、GitHub、社交、Call、Footer 字标 | `founders-intro`、`founder-breath`、`github-repo-cards`、`social-expand`、`call-reveal`、`footer-wordmark-reveal` |
| L3 | 桌面 pin | `desktop-pins`、`fit-closing-pin`、`magnet-hover`（`md+`） |

Pin：`start: "top 72px"`（sticky header，**用 px**）。

## 注册顺序（代码真值）

**`registerHomeScrollMotion`**（全端，`reduced` 关）：

1. `registerGlobalDepthScrub`  
2. `registerManifestoScroll`  
3. `registerHeroWordmarkStagger`  
4. `registerHeroChoreography`（`hero-wave-calm` 触发 `#founders`）  
5. `registerFoundersIntro` → `registerFounderBreath` → `registerGithubRepoCards`  
6. `registerSocialExpand` → `registerCallReveal` → `registerFooterWordmarkReveal`  

**`registerHomeMobileMotion`**（`< md`）：`registerFitReveal`（`#fit`）。

**`registerHomeDesktopMotion`**（`md+`）：`registerDesktopPins` → `registerFitClosingPin` → `registerMagnetHover`。

> `SG_HOME_MOTION_PIPELINE` 列出 `fit-reveal` 作索引；**实际仅在 mobile 函数中调用**，避免与桌面 pin 双注册。

## WebGL 与性能守卫

| 组件 | 挂载条件 | 停更条件 |
|------|----------|----------|
| `HeroWaveCanvas` | `lite` / `full` | IO 离屏、`frameloop="never"` |
| `WaterVolumeFx` | 仅 `full` | `isSgAtmospherePaused()` |
| `UnderwaterLightStage` | 始终（DOM） | `isSgAtmospherePaused()` 跳过写样式 |
| `GlowRiver` | 始终 | `data-sg-atmosphere-paused` 时 CSS 暂停动画 |

`SgPerformanceGuards`：Hero 可见比例低于 10% 时设 `data-sg-atmosphere-paused`。

调参顺序：Glow blur/振幅 → Hero Bloom/opacity → shader 复杂度。`dpr` ≤ 1.5。

## 微信 / B 站

- 微信横滑：**纯手控**，无竖滚绑 `scrollLeft` 的 ST。
- B 站预取：**滚动测量**，勿 IO + `vh` rootMargin。
