# 02. 视觉与动效系统

## 视觉原则

- 文字优先：内容可读性高于背景表现
- 克制高级：有生命感，但不能“抢戏”
- 稳定第一：禁止亮度闪烁、刷新跳变、局部突变

## 颜色与排版

- 颜色令牌定义在 `app/globals.css`（`--background`、`--foreground`、`--muted` 等）
- 主标题使用 `wordmark-display`，统一字偶距与渲染特性
- 不再使用暗色模式自动改写根色值，避免状态切换突变

## 动效设计边界

### 允许

- 位移（`x/y/translate`）
- 裁切揭示（`clip-path`）
- 轻微模糊/饱和度呼吸（仅背景层）
- 低频长周期动画（避免“抖动感”）

### 禁止（正文区域）

- 滚动中直接改正文 `opacity/autoAlpha`
- 高频闪烁、明显明暗抽动
- 与滚动解耦但强烈的常驻动画

**社交矩阵展开、访谈叠卡等滚动编排**：见 **`wiki/05-站点深度与模块设计草案.md` → 第六轮**；动的是 **容器 wrapper** 的 `transform` / `clip-path`，正文叶节点仍遵守上表禁止项。

## Glow River 与 Orb

- Glow River：
  - 主路径：提供连续“能量河流”轮廓
  - Shimmer 路径：微弱纹理流动，强化生命感
- Orb：
  - 外层 aura + 内核 core
  - 慢速浮动 + 呼吸，不改变正文对比度

## Manifesto 首屏：Shader 波浪 + 跑马灯

- Shader 层（WebGL）：
  - 低频 fbm 场 + 宽带状 `smoothstep` 光带，偏蓝青品牌色；指针小半径扰动（桌面更强、触控更弱）
  - `Bloom` 强化发光感；**强度与振幅基线以 `hero-wave-canvas.tsx` 顶部常量及 `00-Vision` 文档 Layer 1 表格为准**
- 与滚动的衔接：
  - Hero 根节点上的 `--wave-distortion`、`--wave-opacity` 由 GSAP 在接近 `#proof` 时 scrub 到较低值，形成「首屏躁、二屏收」的对比
- 跑马灯：
  - `.sg-marquee-track`：大号镂空描边字（小屏 `1.5px` stroke，`md+` 为 `2px`），`prefers-reduced-motion` 下停滚动动画

## 背景层约束（当前实现）

- **全站**：Glow River + Orb 仍以 CSS/SVG 为主，余光可感知
- **首屏**：在可读性前提下允许 WebGL；性能与降级策略见 `03-性能与自动降级策略.md`
- 一旦出现卡顿风险：优先调低 Bloom/波浪强度、确认视口外已停帧，再考虑动 SVG 层

## 无障碍（A11y）

- `prefers-reduced-motion: reduce` 时：
  - 滚动与动画降级为静态/近静态
  - **不挂载** `HeroWaveCanvas`（无 WebGL）；跑马灯轨道动画由 `globals.css` 关闭
  - 背景保持可读，不依赖动效传递信息

## 光学补偿（暗底白字）

- `body`：**`-webkit-font-smoothing: antialiased`**、**`-moz-osx-font-smoothing: grayscale`**、默认 **`font-weight: 300`**（标题等仍用 Tailwind 字重类覆盖）
- 巨型跑马灯：**`letter-spacing: -0.02em`**（`.sg-marquee-track`）
