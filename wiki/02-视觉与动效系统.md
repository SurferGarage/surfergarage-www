# 02. 视觉与动效系统

## 视觉原则

- 文字优先：内容可读性高于背景表现
- 克制高级：有生命感，但不能“抢戏”
- 稳定第一：禁止亮度闪烁、刷新跳变、局部突变

## 颜色与排版

- 颜色令牌定义在 `app/globals.css`（`--background`、`--foreground`、`--muted` 等）
- **Manifesto 英文骨牌**：`wordmark-display` 仅用于 **`SURFERGARAGE` 一行**（`IBM Plex Sans` / `--font-en`）：**`font-weight: 700`**、**`letter-spacing: -0.04em`**、`line-height` 收紧、`text-rendering: optimizeLegibility`；中文「浪前」用 **`--font-zh`** 独立样式，**不**套用本类
- 不再使用暗色模式自动改写根色值，避免状态切换突变
- **Editorial 纸色阶（V2.0）**：`--paper-0` … `--paper-4`、`--surface-mode` / `--ambient-mode` 控制 Hero 水下 → `#proof` 出水线 → 内容区 paper 过渡；`.editorial-*` 工具类（eyebrow / mono / serif）
- **Blueprint 氛围**：`SgAmbientGrid`（`.sg-grid-base` 点阵 + `.sg-grain`）；`GlowRiver` 的 `.sg-river-deep` 全页 subtle 深蓝纹理；出水线后 `--surface-mode` 升高时显形
- **叠卡呼吸带**：`.sg-founder-breath-glow`（`globals.css`）慢速漂移渐变；`prefers-reduced-motion: reduce` 下关动画；与 `register-founder-breath` GSAP scrub 叠用

## 动效设计边界

### 允许

- 位移（`x/y/translate`）
- 裁切揭示（`clip-path`）
- 轻微模糊/饱和度呼吸（仅背景层）
- 低频长周期动画（避免“抖动感”）

### 禁止（正文区域）

- 滚动中直接改正文 `opacity/autoAlpha`
- 高频闪烁、明显明暗抽动
- 与滚动解耦但强烈的常驻动画

**社交矩阵展开、访谈叠卡等滚动编排**：见 **`wiki/05-站点深度与模块设计草案.md` → 第六轮**；动的是 **容器 wrapper** 的 `transform` / `clip-path`，正文叶节点仍遵守上表禁止项。

**GitHub 仓库卡（Founders 文章卡内）**：`register-github-repo-cards` 对整块 `[data-github-repo-card]` 做 **clip-path 自下揭示 + `y` 位移**，`expo.out` 入场（与 The Call 的 reveal 气质一致）；避免对卡片内正文单独做 scrub opacity。

**滚动 scrub / 入场时长与 stagger**：集中在 **`lib/sg-motion-system.ts`**（`SG_SCRUB` / `SG_TRIGGER` / `SG_SELECTORS` / `SG_ST_ID`），由 **`components/motion/sg-motion-primitives.ts`** 实现，**`sg-home-registry.ts`** 定注册顺序。

**全站注册顺序、Lenis、`--depth-t` / `--wave-*` 与 WebGL 并行关系**：见 **`wiki/07-动画编排与统筹.md`**（新增动效只改 system + primitives + 对应 `register-*`）。

## Glow River 与 Orb

- Glow River：
  - 主路径：提供连续“能量河流”轮廓
  - Shimmer 路径：微弱纹理流动，强化生命感
  - **周期**：`globals.css` 中 drift / breath / shimmer 使用 **非整数倍秒**（约 24s / 18s / 28s），减少与 Call 区 Orb（约 20s）**相位锁死**造成的机械感
- Orb：
  - 外层 aura + 内核 core
  - 慢速浮动 + 呼吸，不改变正文对比度

## 首页水下氛围（体积 GLSL + CSS 光球）

- **`WaterVolumeFx`**（`components/water-volume-fx.tsx`）：叠在 **`sg-main-depth`** 与 **`GlowRiver`** 之上、**`UnderwaterLightStage`** 之下；全屏 **screen** 混合的轻量 Shader，模拟 **焦散网、顶光丁达尔锥、悬浮微粒**；与整页 **`--depth-t`**、浪速 **`--wave-scroll-vel`** 同轨，滚动越深光越收。
- **`UnderwaterLightStage`** + **`app/globals.css` 的 `.uwl-*`**：CSS **倒置水面高光**、顶缘 aperture、多束 **`.uwl-ray`** 丁达尔、随滚动下沉的 **光球**（青→金）；**`--uwl-tyndall`** 随深度减弱 CSS 光柱强度，避免与 GLSL 重复发灰。
- **可读性**：正文仍在 **`main` `z-[3]`**；氛围层 **`pointer-events-none`**；调光时优先动 **shader 输出 alpha** 或 **`.uwl-*` opacity**，勿压正文对比度。

## Manifesto 首屏：Shader 波浪 + 纵深可读层

- Shader 层（WebGL）：
  - 低频 fbm 场 + 宽带状 `smoothstep` 光带，偏蓝青品牌色；指针小半径扰动（桌面更强、触控更弱）
  - `Bloom` 强化发光感；**强度与振幅基线以 `hero-wave-canvas.tsx` 顶部常量及 `00-Vision` 文档 Layer 1 表格为准**
- 与滚动的衔接：
  - Hero 根节点上的 `--wave-distortion`、`--wave-opacity` 由 GSAP 在接近 **`#founders`** 时 scrub 到较低值，形成「首屏躁、进入片场前收」的对比
- 首屏与全站纵深：不设整屏 scrim；主背景由 **`sg-main-depth-paper` + `sg-main-depth-submerge`（118vh）+ `--depth-t` / `--ambient-mode`** 连续呈现；Hero→Proof 靠 **`#manifesto::after`** 与 Proof 负 margin 叠层，**勿**插独立 bridge 条（见 **`wiki/04` §12**）；正文靠轻 **`text-shadow`** 压眩光
- **`--depth-t` 数据完整性**：须为有限数且落在语义 **`[0,1]`**（由 **`register-global-depth-scrub`** 的 **`formatSafeDepthProgress`** 写入；见 **`wiki/04` §9**）。若 `:root` 上出现非法字符串，**`--sg-dt`** 与依赖它的 **`color-mix`** 可能整条失效，表现为浅灰底叠 **screen** 氛围层的异常亮条。

## 背景层约束（当前实现）

- **全站**：Glow River + Orb 仍以 CSS/SVG 为主，余光可感知
- **首页额外**：**`WaterVolumeFx` + `UnderwaterLightStage`** 叠在纵列渐变之上（见 `01` z 栈）；与 Hero 底床 **分工**：Hero 负责 **海面几何 + Bloom**，首页氛围层负责 **体积光感**（勿两套叙事抢同一频段过曝）
- **首屏**：在可读性前提下允许 WebGL；性能与降级策略见 `03-性能与自动降级策略.md`
- 一旦出现卡顿风险：优先调低 Bloom/波浪强度、确认视口外已停帧，再考虑动 SVG 层；首页第二 Canvas 可降 **`WaterVolumeFx`** 的 `dpr` 或暂时移除挂载做 A/B

## 无障碍（A11y）

- `prefers-reduced-motion: reduce` 时：
  - 滚动与动画降级为静态/近静态
  - **不挂载** `HeroWaveCanvas`（无 WebGL）
  - **不挂载** `WaterVolumeFx` 与 `UnderwaterLightStage`（无第二套 WebGL / 大面 CSS 光动）
  - 背景保持可读，不依赖动效传递信息

## 光学补偿（暗底白字）

- `body`：**`-webkit-font-smoothing: antialiased`**、**`-moz-osx-font-smoothing: grayscale`**、默认 **`font-weight: 300`**（标题等仍用 Tailwind 字重类覆盖）
