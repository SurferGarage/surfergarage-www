# 09. 目录结构与文件地图

> **用途**：新成员 / Agent 快速定位「改哪里」。细节动效见 `07`，排障见 `04`，模块产品语义见 `05`。  
> **仓库根**：`surfergarage-www/`（Git 独立；Cursor 工作区常为上级 `site 2.0/`）。

## 工作区与仓库

```
site 2.0/                    ← Cursor 工作区（可含 .history 等本地项，非业务代码）
└── surfergarage-www/        ← Next.js 16 主站（本文件描述范围）
```

**技术栈**：Next.js 16 App Router · React 19 · TypeScript · Tailwind CSS 4 · GSAP + Lenis · Three.js（受 `lib/sg-webgl-policy.ts` 控制）

**常用命令**（`package.json`）：

| 命令 | 说明 |
|------|------|
| `npm run dev` | 开发服务器 |
| `npm run dev:preview` | 生产构建后本地预览（省 dev 内存） |
| `npm run build` | 生产构建 |
| `npm run clean` | 删除 `.next` 缓存 |

## 顶层目录职责

| 目录 / 文件 | 职责 |
|-------------|------|
| `app/` | 路由、全局布局、`globals.css`、API Route |
| `components/` | UI 与 Client 组件；`motion/` 为 GSAP 注册 |
| `lib/` | 数据、工具、Hooks（无 JSX） |
| `public/` | 静态资源（`/team/*`、`/wechat-feed/*`、`/founders/*` 等） |
| `scripts/` | 维护脚本（如微信封面规范化） |
| `wiki/` | 工程文档（本目录） |
| `.github/` | CI、`pull_request_template`、Issue 模板 |

## `app/` — 路由层

| 路径 | 作用 |
|------|------|
| `layout.tsx` | 根布局：字体、JSON-LD、`SmoothScroll`、`HeroWaveCanvas`、B 站 `preconnect` |
| `page.tsx` | **首页**单页长滚动（见下节纵向顺序） |
| `globals.css` | 设计 token、模块样式、动效 CSS |
| `loading.tsx` / `error.tsx` / `not-found.tsx` | 全局加载 / 错误 / 404 |
| `opengraph-image.tsx` | OG 分享图 |
| `robots.ts` / `sitemap.ts` | SEO |
| `privacy/page.tsx` | 隐私政策 |
| `api/bilibili/view/route.ts` | B 站 `view` 元数据代理（封面、aid/cid） |

### 首页纵向模块（`app/page.tsx`）

自上而下：

1. **氛围层**：`SgAmbientGrid`、`GlowRiver`、`WaterVolumeFx`、`UnderwaterLightStage`（均读 `--depth-t` / `--ambient-mode`）
2. **`HomeHero`** → `#manifesto` 宣言
3. **`HomeProof`** → 出水线 / 「内容一览」
4. **`HomeFounders`** → `#founders` 浪前片场（四屏 sticky stack）
5. **`data-social-founders-trench`** → 片场与触点之间的海沟
6. **`HomeSocial`** → `#social` 各平台
7. **`HomeCall`** + **`HomeFit`** → `#call` 联络（`#fit` 为 sr-only 锚点保留）
8. **`SiteFooter`**
9. **`HomeScrollChoreography`** → 挂载 `components/motion/*` 编排

顶栏锚点（`lib/site-nav.ts`）：`#manifesto` · `#founders` · `#social` · `#call`

### B 站视频（唯一嵌入实现）

| 文件 | 说明 |
|------|------|
| `bilibili-embed-player.tsx` | 官方 iframe；`aid/cid` 直出 URL；`lazy` / `eager` 模式 |
| `bilibili-episode-cover.tsx` | 封面占位（API meta） |
| `lib/bilibili-player.ts` | URL 构建、`fetchBilibiliVideoMeta`、`prefetchBilibiliPlayerDocument` |
| `lib/bilibili-embed.ts` | `pauseBilibiliEmbed`（postMessage） |
