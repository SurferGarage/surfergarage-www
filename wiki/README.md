# SurferGarage V2 Wiki

本目录用于沉淀当前官网 V2 的核心工程信息，面向两类读者：

- 维护开发者（快速理解架构、风险、调参入口）
- Agent（避免重复踩坑，按既定策略继续迭代）

## 文档索引

- `00-项目总览.md`：目标、技术栈、当前状态、已知风险
- `01-架构与模块说明.md`：目录职责与关键组件关系（含 Hero WebGL 与滚动联动）
- `02-视觉与动效系统.md`：Lenis/GSAP、首屏 Shader/跑马灯、CSS-SVG 氛围层约束
- `03-性能与自动降级策略.md`：Glow/SVG 与首屏 WebGL 的分层守则
- `04-维护与排障手册.md`：常见问题定位、修复步骤、发布前检查

## 推荐阅读顺序

1. 先读 `00-项目总览.md`
2. 再读 `03-性能与自动降级策略.md`
3. 最后按任务查阅 `01/02/04`

## 当前维护原则（必须遵守）

- 先保证稳定亮度与流畅度，再谈特效强度
- 禁止新增“会改正文亮度”的滚动动画（opacity/autoAlpha 直改正文）
- 所有动效都必须尊重 `prefers-reduced-motion`
- 全站氛围层以 CSS/SVG 为主；首屏 WebGL 为受控增强，须遵守 `03` 中的护栏与调参顺序
