# Support

## Before Asking for Help

Please include:

- What you expected
- What actually happened
- Reproduction steps
- Environment (OS, browser, device)
- Screenshots/recording when UI behavior is involved

## Where to Ask

- Bug / feature tracking: GitHub Issues
- Security concerns: follow `SECURITY.md` (private disclosure)

## Good Issue Titles

- `[Bug] Hero text flickers on Safari iOS 17`
- `[Feature] Add static fallback for shader background`
