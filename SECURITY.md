# Security Policy

## Supported Versions

We currently provide security support for the active `main` branch.

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities.

Instead, report privately with:

- Title: `[Security] <short description>`
- Affected area (route/component/module)
- Reproduction steps or proof-of-concept
- Potential impact
- Suggested mitigation (optional)

Send reports to:

- Email: `edisonxu0909@gmail.com`

## Response Expectations

- Initial response target: within 72 hours
- Triage result: severity + fix path
- Remediation: as soon as practical based on severity and exploitability

## Scope

This policy applies to:

- Application code in this repository
- Build/deploy configuration in this repository

Out of scope:

- Third-party vulnerabilities with no exploitable path in this project
- Issues requiring privileged local machine access without project impact
