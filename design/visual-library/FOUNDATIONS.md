# Foundations · 视觉基础

## 1. 色彩角色

| Token | HEX | 角色 | 建议占比 |
|---|---:|---|---:|
| Electric Blue | `#0009E2` | 品牌动作、标题强调、方向线 | 10–25% |
| Deep Navy | `#060644` | 视频底、可信度、长时间观看 | 45–80% |
| Cyan | `#27D7C7` | 节点、当前状态、交互提示 | ≤ 8% |
| Paper | `#F4F6FA` | 教程、招募、文字密集物料 | 60–90% |
| Ink | `#0B0C10` | 浅底正文与对比 | 10–30% |
| Cool Grey | `#8B93A8` | 时间码、来源、次级信息 | 10–20% |

### 组合规则

- 每个画面最多 **1 个底色 + 1 个主色 + 1 个节点色**。
- Cyan 只负责“现在 / 活跃 / 可点击 / 关键节点”，不能作为大面积背景。
- 视频长镜头优先 Deep Navy；教程、清单与招募优先 Paper。
- 禁止紫色渐变、霓虹彩虹和无语义的蓝紫光球。

## 2. 字体层级

| 层级 | 推荐字体 | 用途 | 画面占比 |
|---|---|---|---|
| Display | Helvetica / Arial Black / IBM Plex Sans Bold | 发布标题、人物姓名、大数字 | 8–18% 高度 |
| Editorial | EB Garamond / Instrument Serif | 引言、观点、长标题中的人文层 | 6–12% 高度 |
| Chinese | OPPO Sans / Noto Sans SC / Microsoft YaHei | 中文标题与正文 | — |
| Signal | IBM Plex Mono / Cascadia Mono | 标签、时间码、编号、来源 | 1.6–3% 高度 |

### 标题规则

- 标题建议 8–22 个汉字；超过 2 行时重新编辑，不缩成小字。
- 中文标题不全粗；只用颜色或一个重量层级强调关键词。
- Mono 层永远不抢主标题：字号不超过主标题的 24%。
- 英文品牌名统一写作 `SURFER GARAGE` 或 `Surfer Garage`，不混用 `SurferGarage` 作为展示标题。

## 3. 网格与安全区

| 画幅 | 成品尺寸 | 列数 | 外边距 | 字幕安全区 |
|---|---:|---:|---:|---:|
| 横屏 | `1920 × 1080` | 12 | 96 px | 左右 120 / 上下 90 |
| 竖屏 | `1080 × 1920` | 6 | 72 px | 左右 72 / 上 150 / 下 260 |
| 小红书 / IG | `1080 × 1350` | 6 | 72 px | 四边 72 |
| 方形 | `1080 × 1080` | 6 | 64 px | 四边 64 |

- 主标题左边缘、人物眼睛、数据基线至少有两者落在同一列线上。
- 不把重要信息放进竖屏底部 260 px，避免平台 UI 遮挡。
- Logo 不贴角：最小安全距离为 Logo 高度的 0.75 倍。

## 4. 标志使用

- 唯一允许使用的现行母版是 [`../../public/brand-sg-logo.png`](../../public/brand-sg-logo.png)；在 SVG、横版锁定和单色版完成前，不自行描摹或重组。
- Logo 不进入生图 prompt 的最终成片层。生成画面必须预留锁定区，导出时再放入正式文件。
- 首选组合标用于片尾、活动主视觉和品牌页。
- 当前没有获批的独立箭头 / `SG` 标记，因此小尺寸角标宁可不放，也不能从组合标中自行裁切。
- 视频中 Logo 最多出现三次：片头识别、必要水印、片尾；不持续放大 Logo。
- 水印透明度 72–88%，位于右上或左上安全区，不与人物脸部争夺注意力。

## 5. 图片处理

### 人物

1. 真实现场优先，保留环境证据；不抠成“商业精英肖像”。
2. 裁切优先眼神方向留空间；眼睛落在上 40% 区域。
3. 暗底画面：降低背景饱和度 10–25%，Electric Blue 只进入图形层。
4. 浅底画面：允许人物硬切边，但必须保留一条真实环境或物件线索。

### 产品 / 屏幕

- 产品演示只放真实界面；不使用伪造 UI 截图。
- 一屏最多突出一个动作，用 Frame + Node 标出，而不是放 5 个箭头。
- 屏幕录制保持 1× 或 1.25×，关键动作前后各留 8–12 帧。

### 纹理

只允许：细网格、微噪点、低对比水下光、扫描线、等高线式波纹。任何纹理透明度不超过 14%。

## 6. 图形语法

| 元素 | 含义 | 使用方式 |
|---|---|---|
| Wave | 趋势尚在形成 | 1–3 条连续曲线，不做海浪插画 |
| Signal line | 信息正在传播 | 水平推进、声波或数据轨迹 |
| Node | 值得注意的时刻 | 单点高亮；每画面 1–4 个 |
| Frame | 编辑判断 / 选中 | 角标或不闭合框，不使用厚卡片 |
| Arrow | 方向 / 下一步 | 只指向明确目标 |
| Grid | 系统与坐标 | 低对比背景，不作为主视觉 |

## 验收

- 缩到手机宽度后，3 秒内仍能读到主标题。
- 转成灰度后，层级仍成立。
- 去掉 Logo 后，仍能从蓝、节点、波与框识别为浪前。
- 画面中没有无法解释其作用的装饰元素。
