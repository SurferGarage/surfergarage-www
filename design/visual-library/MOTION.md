# Motion Language · 动效语言

## 核心判断

浪前动效不是“流体科技感”，而是**信号被发现、判断、放大并传出去的过程**。

```text
quiet field → weak signal → node lock → editorial frame → wave propagation
```

## 动效原语

| 名称 | 画面 | 时长 | 缓动 | 用途 |
|---|---|---:|---|---|
| Signal Wake | 细线从 15% 亮度升到 100% | 400–650ms | `cubic-bezier(.22,1,.36,1)` | 片头 / 章节开始 |
| Node Lock | 点扩散一次后稳定 | 360–520ms | ease-out | 人物、数据、关键词锁定 |
| Frame Resolve | 四个角分两拍出现 | 480–720ms | ease-out | 编辑选择、产品重点 |
| Wave Pass | 波线横向推进 8–16% | 900–1600ms | ease-in-out | 段落转场 |
| Type Set | 按行 / 词组出现，不逐字打字 | 320–700ms | ease-out | 标题、引文 |
| Data Count | 仅主数字计数 | 600–1000ms | ease-out | 数据证明 |
| Field Cut | 真实素材硬切 + 2 帧蓝闪 | 2–4 frames | linear | 现场 montage |

## 节奏单位

以 **25 fps** 为默认：

- 微动作：6–10 帧
- 标题进入：12–18 帧
- 章节卡停留：35–60 帧
- 品牌识别片：75–150 帧
- 同一画面中最多 2 个动作同时发生

## 转场

### 允许

- 硬切：真实现场、采访反应、动作连续性
- Signal wipe：1 px 线经过后切换内容
- Frame match：用同一框位置匹配两个镜头
- Wave displacement：低幅度、短时长，只用于章节级转场
- Luma fade：水下光 / 白墙等有真实亮度依据的镜头

### 禁止

- 通用 glitch、RGB 分离、粒子爆炸
- 每个镜头都 zoom in / zoom out
- 旋转卡片、3D 翻页、无来源 HUD
- 长时间打字机效果
- Logo 弹跳或持续呼吸

## 字幕系统

- 中文字幕默认每行 13–18 个汉字，最多两行。
- 白字 + 75% Deep Navy 底或 2 px 暗描边；不使用纯黑粗条。
- 重点词只用 Electric Blue 或 Cyan 二选一。
- 人名下三分之一：`姓名 / 角色` + `INSIGHT` 标签；进入 10–14 帧，停留 ≥ 3 秒。
- 竖屏字幕底边距 ≥ 300 px。

## 声音方向

视觉库不含成品音效，但声音必须遵守同一语义：

| 声音 | 对应 |
|---|---|
| 低频水下底噪 | Field / 环境存在 |
| 短促正弦 ping | Node lock |
| 细窄噪声 sweep | Signal line / 章节切换 |
| 机械轻触 / 磁带 click | Frame / 时间码 |
| 真实现场声 | 人物与事件，不被音乐完全覆盖 |

音乐优先 80–110 BPM、克制打击、低旋律密度；避免“企业励志高潮”和赛博朋克模板音乐。

## Reduced motion / 静态替代

- 所有动作必须有可读的最终静帧。
- 关闭动效时，Node 保持 100% 亮度、Frame 完整、Wave 不位移。
- 发布图应从视频关键帧直接复用，而不是另起一套风格。

## 动效验收

- 静音时仍能看懂；闭眼只听时仍有清晰段落。
- 动画停在任意一帧都没有文字被遮挡或未完成状态。
- 动效说明了状态变化，而不只是“让它动起来”。
- 片尾 CTA 在手机上至少有 1.5 秒完整可读时间。
