# Template Matrix · 模板矩阵

## 核心模板

| ID | 模板 | 用于 | 必须元素 | 不要做 |
|---|---|---|---|---|
| `T01 Launch` | 项目 / 栏目发布 | 新栏目、网站、计划、开源仓库 | 标签、单一主张、日期 / 状态、方向波 | 堆功能、写完整介绍 |
| `T02 Founder` | 人物封面 | Surfing Founder、播客嘉宾、短访谈 | 人物、姓名、角色、一期编号 | 过度磨皮、人物居中证件照 |
| `T03 Quote` | 观点切片 | 金句、方法论、文章摘要 | 引文、说话者、来源 | 没有来源、超过 60 字 |
| `T04 Proof` | 数据 / 证据 | 增长、访谈样本、活动成果 | 一个主数字、解释、口径 | 数据装饰化、伪精确 |
| `T05 Chapter` | 视频章节 | 转场、议题、地点、阶段 | 编号、标题、时间码 | 复杂背景、过长停留 |
| `T06 End` | 片尾 / CTA | 关注、阅读、加入、访问 | Logo、唯一 CTA、渠道 | 同时放 4 个二维码 |

## 尺寸映射

| 渠道 | 首选画幅 | 次选 | 时长 / 页数 |
|---|---|---|---|
| B 站 / YouTube 发布视频 | 16:9 | — | 30–90s |
| 视频号 / 抖音 / Reels | 9:16 | 1:1 | 15–45s |
| 小红书封面 / 图文 | 4:5 | 1:1 | 1–8 页 |
| 公众号首图 | 16:9 | 2.35:1 裁切 | 单图 |
| X / LinkedIn 发布 | 16:9 | 1:1 | 单图 / 4 图 |
| 活动屏幕 / 演讲 Keynote | 16:9 | — | 章节卡 |

## 内容组合

### Surfing Founder

```text
T02 人物封面 → T03 核心判断 → T04 一条证据 → T05 章节 → T06 阅读 / 观看
```

### 浪前对话

```text
Cold open 真实一句话 → T02 双人 / 嘉宾 → 对谈切片 → T05 议题 → T06 完整节目
```

### Startup Playbook

```text
T01 问题发布 → T04 框架 / 数据 → 步骤卡 × 3 → T03 结论 → T06 开源仓库
```

### 活动 / 现场

```text
T01 时间地点 → 真实现场 montage → T04 人数 / 项目 → T03 参与者判断 → T06 下一场
```

## 文案字数

| 元素 | 横屏 | 竖屏 |
|---|---:|---:|
| 主标题 | 8–22 汉字 | 6–16 汉字 |
| 副标题 | 18–44 汉字 | 12–30 汉字 |
| 引文 | 18–60 汉字 | 14–42 汉字 |
| 标签 | 2–10 字符 | 2–8 字符 |
| CTA | 4–12 汉字 | 4–10 汉字 |

当内容超过限制，优先拆成下一张 / 下一镜，不通过缩小字号解决。
