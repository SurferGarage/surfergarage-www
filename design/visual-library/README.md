# 浪前视觉库 · Surfer Garage Visual Library v1

> 目标：让任何团队成员在不重新“发明设计”的前提下，稳定产出像同一家公司做的发布视频、人物内容、活动物料和社交媒体切片。

这套库不是一份更长的品牌手册，而是现有 VIS 的**成片生产层**。第一版先建立具有明确艺术指导的母视觉，再由母视觉扩成视频关键帧、人物封面、洞察封面和社交切片；不使用浏览器 Canvas、CSS 图形或自动模板代替设计。

Logo 只允许使用仓库中的正式文件 [`../../public/brand-sg-logo.png`](../../public/brand-sg-logo.png)。生成模型负责画面，不负责重画 Logo；AI 输出中的任何拟态 Logo 都视为废稿。

## 视觉母体

浪前所有画面只使用一套母体：

```text
FIELD（真实现场）
  + SIGNAL（被发现的信号）
  + WAVE（正在形成的趋势）
  + FRAME（浪前的编辑判断）
```

- **FIELD**：人物、产品、现场、手稿与真实屏幕，不使用无关“科技感图库”。
- **SIGNAL**：线、节点、时间码、标签、数据读数；表达“这里有值得注意的东西”。
- **WAVE**：曲线、推进方向和节奏；表达成长、传播与尚未成为共识的变化。
- **FRAME**：留白、裁切、标题层级和编辑语气；浪前不是转发素材，而是在做选择。

## v1 范围

- 9 个图像主导的母视觉与成片关键帧：发布、人物、对谈、教程、活动、洞察、品牌片分镜与片尾
- 4 种画幅规则：`16:9`、`9:16`、`4:5`、`1:1`
- 6 个内容场景：发布、人物、引言、数据、章节、片尾
- 4 套视频配方：6 秒识别片、15 秒竖屏、30 秒发布片、60–90 秒人物预告
- 统一的动效时间、缓动、字幕安全区、图片处理与声音方向
- 可复制的设计 brief 与验收清单

## 成熟度边界

这一版目标是成熟团队视觉系统的约 **70%**：先解决“每一帧是不是浪前、有没有成熟公司的艺术指导”这一层。暂不包含定制字体、完整音效包、After Effects / Premiere 工程、定制实拍与专业调色；这些属于后续 30%。

## 使用原则

1. **一个画面只讲一个判断。** 标题、数字、人物三者只能有一个做主角。
2. **先真实素材，后图形增强。** 图形用于指出信息，不用于掩盖素材不足。
3. **保持识别，不做组件堆叠。** 一帧最多包含一个主素材、一个品牌母题和一个信息层；波、线、节点、网格不同时出现。
4. **不借 Claude 的皮肤。** 学习其模块化、克制和产品证据，但保留浪前的蓝色信号系统与真实创业现场。
5. **所有发布物先过验收清单。** 见各文档末尾。
